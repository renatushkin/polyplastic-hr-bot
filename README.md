# Корсик — MAX HR-бот (MVP для хакатона)

## Быстрый запуск в WSL

```bash
cd ~/projects/polyplastic-hr-bot
# Сначала сделайте резервную копию вашего текущего проекта!
python3 -m venv .venv
source .venv/bin/activate
cp .env.example .env
nano .env  # укажите MAX_BOT_TOKEN, не отправляйте его никому
python -u max_adapter.py
```

Зависимости для запуска MAX-демо не требуются: стандартная библиотека Python 3.10+.
Для дополнительного импорта Excel через `import_excel.py` потребуются pandas и openpyxl, а также совместимая схема БД; этот импорт **не включён в работающий демосценарий**.

## Роли

- Оба телефона пишут **одному и тому же** боту MAX.
- С аккаунта HR сначала отправьте `/myid`; внесите полученное число в `.env` как `HR_MAX_USER_ID`, перезапустите бота.
- HR: `/start`, `/tickets`, `/reply НОМЕР текст`.
- Сотрудник: `/start`, кнопки, `/continue`, `/ask вопрос`.
- Если поиск по утверждённой базе не нашёл ответ, автоматически создаётся обращение HR. После назначения HR бот отправляет ему открытые обращения.

## Данные

- `data/demo/scenario.json` — **только демонстрационная адаптация из 6 шагов**, сохраняет прогресс в SQLite.
- `data/demo/knowledge.json` — текстовые фрагменты из **двух приложенных корпоративных презентаций**. Ответы в `LLM_MODE=extractive` возвращают цитируемый фрагмент, а не свободную генерацию.
- `docs/` — исходные файлы, включая полный Excel Корсика и PDF. **PDF со сканами не индексированы автоматически**: нельзя утверждать, что бот отвечает по ним.
- `data/images/` — 16 настоящих изображений Корсика; **отправка изображений через MAX ещё не подключена**.
- `database.py`, `schema.sql`, `import_excel.py` сохранены без изменений из переданных материалов. Важно: в текущих исходниках есть две независимые схемы БД (`database.py` и `db.py`), поэтому импорт Excel Анны требует отдельной интеграции и проверки.

## Демонстрация

1. Сотрудник: `/start`, проходит шаги кнопками.
2. Сотрудник: `/ask Какие правила установлены для подарков стоимостью 3000 рублей?` — должен найти корпоративный фрагмент при подходящем совпадении.
3. Сотрудник: `/ask Как оформить отпуск?` — если подтверждённого ответа нет, создаётся обращение.
4. HR: `/tickets`, затем `/reply НОМЕР Ответ после консультации с HR`.
5. Сотрудник получает ответ HR в том же чате.

Не используйте тестовые ответы как официальные правила компании.

## Ограничения

- Сроки автоматической рассылки, условные переходы полного Excel и вложения MAX не завершены.
- Нет продакшн-авторизации персонала, админки, разграничения HR по отделам и устойчивой очереди доставки; роль HR задаётся одним ID в `.env`.
- Работа MAX API зависит от сети и действующего токена; проверка доставки требует двух реальных аккаунтов.
- Не загружайте `.env` или `runtime/*.db` в GitHub.

# Корсик — стартовый прототип

## Запуск
Python 3.10+; внешние пакеты не требуются.
Из корня проекта: `python main.py`. Откройте http://127.0.0.1:8000.
При необходимости скопируйте `.env.example` в `.env` и заполните настройки.
HR-токен отображается в терминале. Введите его в панели HR.
Сервер привязан только к 127.0.0.1; не публикуйте его в интернет.

## Проверка
1. Выберите demo-gtp и пройдите сценарий: офисный шаг должен пропуститься.
2. Выберите demo-office: шаг GTP должен пропуститься.
3. Спросите «Какое расписание автобуса?» — появится синтетический фрагмент.
4. Спросите «Кто согласовал мой отпуск?» — предложится HR.
5. Нажмите подтверждение передачи. Введите HR-токен, загрузите обращения и ответьте.
6. Ответ появится в переписке того же сотрудника. Шаг адаптации не меняется.
7. Перезапустите сервер: состояние сохранено в runtime/korsik.db.

## Режим модели
По умолчанию `LLM_MODE=extractive`: примитивный лексический поиск и цитирование, НЕ генеративный ИИ и НЕ полноценный production RAG.
Для модели: `LLM_MODE=local` или `remote`, задайте LLM_BASE_URL (с /v1), LLM_MODEL и при необходимости LLM_API_KEY.
Нужен endpoint с совместимым POST /chat/completions. Приложение само модель не устанавливает.
Не отправляйте внутренние/конфиденциальные документы в публичный API без разрешения.

## Что реально реализовано
Сценарий по тегам, кнопочные ответы, сохранение прогресса и переписки, простой поиск по синтетическим фрагментам, интерфейс LLM, обращение и ответ HR в локальном веб-чате.

## Что НЕ реализовано
MAX API/авторизация сотрудников, production RBAC, планировщик по дате выхода, полная загрузка Excel, реальные корпоративные документы, эмбеддинги, проверка достаточности найденного контекста, тональность, персонализированная форма ты/вы (выбор пока только сохраняется), доставка через MAX, промышленная безопасность и масштабирование.
Интерфейс сотрудника — тестовый: employee_id выбирается вручную и не защищён авторизацией.
Примитивный поиск может найти похожий, но недостаточный фрагмент. Не используйте эту версию для реальных кадровых решений.

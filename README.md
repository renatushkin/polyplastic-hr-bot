# Корсик — HR-бот для MAX

Корсик — это чат-бот для адаптации новых сотрудников компании ПОЛИПЛАСТИК. Проект сделан в рамках хакатона «Открой#Моспром».

Основная идея — сделать адаптацию сотрудников удобнее и уменьшить количество однотипных вопросов, которые каждый день получают HR-специалисты.

Бот работает в мессенджере MAX.

## Что умеет бот

В Корсике есть три роли: сотрудник, HR и администратор.

**Сотрудник** может:
- Проходить адаптацию и смотреть свой прогресс.
- Запустить демо адаптации на первые 10 дней.
- Задавать вопросы по документам компании.
- Получать ответы от HR через бота, если в базе знаний не нашлось информации.

**HR** может:
- Работать с реестром сотрудников через Excel.
- Создавать приглашения для новых сотрудников.
- Загружать, заменять и удалять документы в базе знаний.
- Смотреть отчёты по адаптации.
- Отвечать на вопросы сотрудников.

**Администратор** может:
- Управлять доступом к боту.
- Просматривать реестр сотрудников.
- Смотреть статистику.
- Проверять историю загрузки документов.

## База знаний

HR загружает документы компании, а Корсик использует их для поиска ответов на вопросы сотрудников.

Поддерживается загрузка PDF до 50 МБ. Если PDF состоит из сканированных страниц, текст можно распознать с помощью OCR.

Если бот не находит подтверждённый ответ, он передаёт вопрос HR. Сотруднику не нужно искать контакты специалиста и писать ему отдельно.

## Как запустить

Проект написан на Python. Для запуска нужен Python 3.12 и токен бота MAX.

В терминале:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Нужно создать файл `.env` по примеру `.env.example` и указать настройки бота.

Для распознавания сканированных PDF в WSL можно установить Tesseract:

```bash
sudo apt-get install tesseract-ocr tesseract-ocr-rus tesseract-ocr-eng poppler-utils
```

Запуск бота:

```bash
python -u max_adapter.py
```

## Проверка

В проекте есть автоматические тесты. Запустить их можно командой:

```bash
python -m unittest discover -s tests -q
```

## Что пока не идеально

Это прототип для хакатона, поэтому некоторые вещи ещё можно улучшить.

Например, распознавание больших PDF может занимать много времени. Также не все материалы из исходного сценария адаптации сопровождаются изображениями и вложениями.

В будущем можно улучшить обработку документов, интерфейс и развёртывание бота на сервере.

## Используемые технологии

- Python

- Поиск по базе знаний

Проект пока запускается локально, но основную функциональность уже можно проверить прямо в MAX.
